  Design-time sim. No real code — the engine mirrors the locked wayfinder chart (map.md + tickets Q1–Q5) and the
  adapter wire it rides (websocket-adapter W1–W6, verbatim — no re-grilling). Tokens are claim objects standing in for JWTs:
  token.admin (scope platform.*.read + platform.session.write) ·
  token.read (platform.*.read only) · token.bad (expired). Env/config toggles on the
  left drive precedence. Design assumptions to confirm in PRD-TRD: config file is never written by the CLI (operator
  hand-writes it; docs show the example); perms warning fires once per run; watch prints snapshot then NDJSON events with
  no re-render; --watch + --json = pure JSON stream (snapshot compact + NDJSON events);
  exit-5 on Ctrl-C is the only signal path in watch mode.
