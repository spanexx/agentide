### 1.2 CLI `--port-sdk` flag

`packages/agentide/src/start.ts` — after the existing `--port-mcp`
parse block (line 45-62):

```ts
const portSdkRaw = getFlag(flags, "port-sdk", "");
if (portSdkRaw !== "" && portSdkRaw !== "true") {
  const portSdk = Number.parseInt(portSdkRaw, 10);
  if (!Number.isFinite(portSdk)) {
    return result("", `error: invalid port --port-sdk=${portSdkRaw}\n`, 2);
  }
  if (portSdk === 7100 || portSdk === 7200 || portSdk === 7300) {
    return result("", `error: --port-sdk=${portSdk} collides with MCP/WS adapter doors\n`, 2);
  }
  // Stash for the createPlatform call below.
  apiSdkPort = portSdk;
}
```

Add the `apiSdkPort` declaration at the top of `runStart` (near line 28):
`let apiSdkPort: number | undefined;`

Then in the `createPlatform` call (line 117-128) add:
```ts
...(apiSdkPort !== undefined ? { backendRuntimePort: apiSdkPort } : {}),
```

### 1.5 Dev bootstrap — `agentide start --all-doors`

> RETIRED 2026-08-08 (cli-ops-ergonomics D-114): `scripts/start-gateway.mjs`
> is deleted. The CLI is the one dev bootstrap — `agentide start --all-doors`
> opens all four client doors (MCP 7100, WS 7300, SDK 7350, REST 7400).

The dev bootstrap equivalent today is:

```bash
agentide start --all-doors --foreground --default-tenant acme
```

which configures:

```js
createPlatform({
  dataDir: './.agentide/data',
  defaultTenant: { id: 'acme', name: 'Acme' },
  adapterMcp: { host: '127.0.0.1', port: 7100 },
  adapterWs: { host: '127.0.0.1', port: 7300 },
  backendRuntimePort: 7350,   // --all-doors (previously script-only)
  adapterRestPort: 7400,      // --all-doors (A9 REST door)
});
```
