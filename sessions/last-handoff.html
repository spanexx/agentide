Fixed a bundle-crash bug that blocked every agentide CLI subcommand. Root cause: packages/dashboard-core/src/server.ts used fileURLToPath(import.meta.url) at module top level, but esbuild's --format=cjs --platform=node bundle replaces import.meta.url with {}. PR #54 introduced packages/dashboard-core/src/fileloc.ts with a bundle-safe fallback chain (import.meta.url → globalThis.__filename → process.cwd()) plus an AGENTIDE_DASHBOARD_ASSETS env override. Four tests cover the three paths.

Added the --dashboard-port CLI flag. PR #54 added it to cli.ts and start.ts with the same validation pattern as --port-sdk. Also fixed a parser-level bug where --flag=value was silently stored as key flag=value instead of flag: "value" — that was why --dashboard-port=7200 didn't bind 7200. The new parser splits on = (CID:cli-args-001).

Verified end-to-end. npm install -g + agentide start --dashboard-port=7200 → ss -ltn | grep 7200 shows LISTEN, GET / returns the real 1052-byte HTML.

Updated two repo-local skills. ci-cd-agentide/SKILL.md and release-agentide/SKILL.md at /home/spanexx/Shared/Learn/Agent-Bridge-SDK/.agents/skills/. What We Found

Published dashboard-core serves placeholder app.js. curl http://127.0.0.1:7200/assets/app.js returns 81 bytes of the inline P3 placeholder instead of the real 5.7 KB client. Cause: fileloc.resolveAssetsDir() doesn't match the post-publish layout. The server, HTML, and token-mint all work; only the JS client doesn't. Open drift item — needs a dashboard-core release.

Release-please only counts commits scoped to a package path. A fix(agentide): commit touching packages/dashboard-core/src/fileloc.ts bumps agentide but not dashboard-core. Worked around with a manual manifest bump in PR #55.

pnpm 11 -r publish SILENTLY SKIPS already-published versions. The skip check runs BEFORE prepublishOnly, so no bump log line appears. We hit this twice; the recovery recipe is in commit 302d205: sync package.json + .github/release-please-manifest.json to npm state, commit, re-dispatch.

--data-dir may be silently ignored. agentide start --data-dir=/tmp/ag-data returned "./.agentide/data not writable" — the flag didn't reach the gateway start logic. Suspect in start.ts's detached-child path. Open drift item.
